## Candidate Project 1
### Biomedical Problem
Intracranial hemorrhage (ICH) has been implicated in brain midline shift. Early, accurate identification of CT scan structural changes could, therefore, benefit patient outcomes and assessment of the severity of the emergency. As a result, analyzing the relationship between CT image features and the midline shift and whether biological sex differences influences these imaging features would be an important way to contribute to improving clinical care decision-making.

### Possible Research Question
Do CT scan intensity features (i.e. Mean Hounsfield Unit (HU), Asymmetry Index) differ between patients with and without midline shift? How do sex differences contribute to this difference?

### Dataset
The dataset we've selected is: Computed Tomography Images for Intracranial Hemorrhage Detection and Segmentation (v1.3.1), published by Murtadha Hssayeni on PhysioNet (2020). https://physionet.org/content/ct-ich/1.3.1/ 

### Biggest Uncertainty
Our dataset of choice is restricted access, however getting availability is fairly simple (make an account and sign the data use agreement). The small sample size (82 total, 36 hemorrhage-positive and 46 hemorrhage-negative) could limit statistical power.

Stage 1: CT Inspection and Feature Extraction

Folder: 1_CT inspection_validation/

ExtractHemorrhageFeatures.py: Reads CT scans, hemorrhage masks, and demographic/diagnostic data. Extracts patient-level hemorrhage measurements, including volume, number of affected slices, and HU statistics.

Patient_demographics.csv: Patient demographics and radiologist-provided diagnostic information.

hemorrhage_diagnosis_raw_ct.csv: Slice-level diagnostic labels, including hemorrhage types and fracture labels.

patient_table_with_features.csv: Patient-level output combining demographic and diagnostic information with extracted hemorrhage features.

Stage 2: CT Mask and Label Validation

Folder: 2_CT_mask validation/

ValidateMasksAgainstLabels.py: Compares hemorrhage mask findings with radiologist-provided slice-level diagnostic labels.

mask_label_validation_slices.csv: Slice-level validation results, including mask-positive voxels, hemorrhage classifications, and agreement indicators.

mask_label_validation_patients.csv: Patient-level summary of total slices, matching slices, positive slices, and reported agreement percentage.

These files help assess consistency between the available masks and diagnostic annotations.

Stage 3: Brain-Region Extraction Testing

Folder: 3_Brain-region extraction testing/

InspectBrainMask.py: Tests and visualizes brain-region extraction on a selected CT scan. The current script is configured for patient 71 and is intended for inspection and quality control.

Stage 4: Patient-Level CT Feature Extraction

Folder: 4_Patient-level CT feature extraction/

BuildMLFeatureTable.py: Extracts CT-derived brain features and combines them with patient-level demographic information to build a machine-learning feature table.

ml_features_ct_only.csv: Patient-level feature table containing CT-derived HU statistics and demographic variables.

brain_extraction_qc.csv: Quality-control information for brain-region extraction, including slice counts, voxel counts, extracted volume, and HU statistics.

Stage 5: Whole-Volume Random Forest Baseline

Folder: 5_Whole-volume RF baseline/

TrainRandomForestICH.py: Trains and evaluates baseline random forest models for patient-level ICH classification using demographic-only, CT-only, and combined features.

rf_ich_model_comparison.csv: Compares model performance using metrics such as accuracy, balanced accuracy, sensitivity, specificity, F1 score, ROC AUC, and average precision.

rf_ich_predictions.csv: Stores patient-level predicted probabilities and classifications for the evaluated models.

rf_ich_feature_importance.csv: Reports feature importance from the random forest analysis.

Stage 6: Slice-Level CT Feature Extraction

Folder: 6_Slice-level feature extraction/

BuildSliceLevelFeatureTable.py: Extracts CT-derived features for individual slices and associates them with patient demographics and slice-level hemorrhage labels.

slice_level_ct_features.csv: Slice-level feature table used for machine-learning experiments.

slice_level_feature_qc.csv: Quality-control records for slice processing, including brain voxel counts, slice labels, and processing status.

Stage 7: Slice-Level Grouped Random Forest

Folder: 7_Slice-level grouped RF/

TrainGroupedRandomForestSlices.py: Trains a random forest classifier on slice-level features using grouped cross-validation to keep slices from the same patient together during model evaluation.

rf_slice_grouped_predictions.csv: Stores predicted probabilities, classifications, true labels, and cross-validation fold assignments for individual slices.

rf_slice_feature_importance.csv: Summarizes feature importance across model folds.

rf_patient_predictions_from_slices.csv: Aggregates slice-level predictions into patient-level predictions using maximum slice probability and the mean probability of the three highest-scoring slices.

Stage 8: Nested Threshold Optimization

Folder: 8_Nested threshold optimization/

TuneGroupedRFThreshold.py: Evaluates slice-level random forest predictions using nested cross-validation and selects classification thresholds using inner-fold performance.

rf_nested_threshold_predictions.csv: Contains slice-level probabilities, selected thresholds, predictions, and outer-fold assignments.

rf_nested_threshold_folds.csv: Summarizes threshold selection and performance across cross-validation folds.

This stage investigates how threshold selection affects classification performance while separating threshold tuning from outer-fold evaluation.

Stage 9: Patient-Level Prediction from Slice Probabilities

Folder: 9_Patient-level prediction from slice probabilities/

TrainPatientLevelHemorrhageRF.py: Evaluates patient-level ICH classification using aggregated slice-level prediction scores and nested cross-validation.

rf_patient_nested_predictions.csv: Contains patient-level predictions, selected aggregation methods, thresholds, and fold assignments.

rf_patient_nested_fold_summary.csv: Summarizes the selected prediction method and performance metrics for each outer fold






## Candidate Project 2
### Biomedical Problem
Aging is associated with changes in autonomic cardiovascular regulation, which can affect heart-rate variability (HRV). Understanding how HRV changes across the lifespan may help characterize normal cardiovascular aging and provide a baseline for identifying abnormal autonomic function.
### Possible Research Question
How do heart-rate variability features change with age in healthy adults?
### Dataset
https://physionet.org/content/autonomic-aging-cardiovascular/1.0.0/
### Biggest Uncertainty
Our biggest uncertainty is determining which HRV features are most appropriate to analyze and whether the ECG recordings require substantial preprocessing before reliable HRV measurements can be extracted.
