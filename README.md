## Candidate Project 1
### Biomedical Problem
Intracranial hemorrhage (ICH) has been implicated in brain midline shift. Early, accurate identification of CT scan structural changes could, therefore, benefit patient outcomes and assessment of the severity of the emergency. As a result, analyzing the relationship between CT image features and the midline shift and whether biological sex differences influences these imaging features would be an important way to contribute to improving clinical care decision-making.

### Research Question
Do CT scan intensity features (i.e. Mean Hounsfield Unit (HU), Asymmetry Index) differ between patients with and without midline shift? How do sex differences contribute to this difference?

### Dataset
The selected dataset is Computed Tomography Images for Intracranial Hemorrhage Detection and Segmentation (v1.3.1), published by Murtadha Hssayeni on PhysioNet.

Dataset link: https://physionet.org/content/ct-ich/1.3.1/

Access to the dataset requires a PhysioNet account and acceptance of the applicable data use agreement.

### Biggest Uncertainty
Our dataset of choice is restricted access, however getting availability is fairly simple (make an account and sign the data use agreement). The small sample size (82 total, 36 hemorrhage-positive and 46 hemorrhage-negative) could limit statistical power.

## Machine-Learning Workflow

The `ML.zip` archive contains nine stages of CT inspection, feature extraction, validation, and machine-learning experimentation.

### Stage 1: CT Inspection and Feature Extraction

**Folder:** `1_CT inspection_validation/`

- `ExtractHemorrhageFeatures.py` — extracts patient-level hemorrhage measurements and HU statistics from CT images and masks.
- `Patient_demographics.csv` — demographic and diagnostic information used by the workflow.
- `hemorrhage_diagnosis_raw_ct.csv` — slice-level diagnostic labels, including hemorrhage types and fracture labels.
- `patient_table_with_features.csv` — patient-level table combining extracted features and patient information.

### Stage 2: CT Mask and Label Validation

**Folder:** `2_CT_mask validation/`

- `ValidateMasksAgainstLabels.py` — compares hemorrhage mask findings with diagnostic labels.
- `mask_label_validation_slices.csv` — slice-level validation results.
- `mask_label_validation_patients.csv` — patient-level summaries of slice counts and reported agreement.

These outputs assess consistency between available masks and diagnostic annotations. Agreement in this implemented check should not be interpreted as proof of diagnostic accuracy or complete voxel-level mask accuracy.

### Stage 3: Brain-Region Extraction Testing

**Folder:** `3_Brain-region extraction testing/`

- `InspectBrainMask.py` — inspects and visualizes brain-region extraction for a selected CT scan. The current script is configured for patient 71.

### Stage 4: Patient-Level CT Feature Extraction

**Folder:** `4_Patient-level CT feature extraction/`

- `BuildMLFeatureTable.py` — extracts CT-derived brain features and combines them with patient-level information.
- `ml_features_ct_only.csv` — patient-level CT feature table.
- `brain_extraction_qc.csv` — quality-control information for brain-region extraction, including voxel counts, extracted volume, and HU statistics.

### Stage 5: Whole-Volume Random Forest Baseline

**Folder:** `5_Whole-volume RF baseline/`

- `TrainRandomForestICH.py` — trains and evaluates baseline random forest models for ICH classification using demographic-only, CT-only, and combined features.
- `rf_ich_model_comparison.csv` — model performance comparisons using metrics such as accuracy, sensitivity, specificity, F1 score, ROC AUC, and average precision.
- `rf_ich_predictions.csv` — predicted probabilities and classifications.
- `rf_ich_feature_importance.csv` — feature-importance results.

### Stage 6: Slice-Level CT Feature Extraction

**Folder:** `6_Slice-level feature extraction/`

- `BuildSliceLevelFeatureTable.py` — extracts CT-derived features for individual slices and associates them with patient information and slice-level labels.
- `slice_level_ct_features.csv` — slice-level feature table.
- `slice_level_feature_qc.csv` — quality-control information for slice processing.

### Stage 7: Slice-Level Grouped Random Forest

**Folder:** `7_Slice-level grouped RF/`

- `TrainGroupedRandomForestSlices.py` — trains a random forest classifier using grouped cross-validation to keep slices from the same patient together during evaluation.
- `rf_slice_grouped_predictions.csv` — slice-level predictions and cross-validation fold assignments.
- `rf_slice_feature_importance.csv` — feature-importance summaries.
- `rf_patient_predictions_from_slices.csv` — patient-level predictions aggregated from slice-level probabilities.

### Stage 8: Nested Threshold Optimization

**Folder:** `8_Nested threshold optimization/`

- `TuneGroupedRFThreshold.py` — evaluates slice-level predictions using nested cross-validation and selects thresholds within the inner folds.
- `rf_nested_threshold_predictions.csv` — probabilities, selected thresholds, predictions, and outer-fold assignments.
- `rf_nested_threshold_folds.csv` — threshold-selection and performance summaries across folds.

This stage examines the effect of threshold selection while separating threshold tuning from outer-fold evaluation.

### Stage 9: Patient-Level Prediction from Slice Probabilities

**Folder:** `9_Patient-level prediction from slice probabilities/`

- `TrainPatientLevelHemorrhageRF.py` — evaluates patient-level ICH classification using aggregated slice-level scores and nested cross-validation.
- `rf_patient_nested_predictions.csv` — patient-level predictions, aggregation methods, thresholds, and fold assignments.
- `rf_patient_nested_fold_summary.csv` — prediction-method and performance summaries for each outer fold.
